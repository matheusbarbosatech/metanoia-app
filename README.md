# ⚔️ METANOIA — O Super-App de Transformação Masculina

> **"Da lama do vício até a honra no casamento e na vida com Deus."**  
> *Sistema Operacional de sobriedade e forja de caráter bíblico e neurocientífico para homens de 18 a 35 anos.*

---

## 📖 Visão Geral

O **METANOIA** não é apenas mais um bloqueador de telas ou aplicativo secular frio. Ele é um **discipulado intensivo de 90 dias** construído sobre a união inegociável da **Palavra de Deus (NVI/ARA)** com os fundamentos modernos de **neuroplasticidade e regulação de dopamina** (baseado em Gary Wilson, Tim Chester, Matt Fradd e C.S. Lewis).

O aplicativo pega o homem ferido pela mão, quebra o ciclo de dopamina barata, combate o transe noturno e o conduz pelos 5 degraus da maturidade até o sacerdócio do lar.

## 🛡️ Os 4 Pilares do Ecossistema

### 1. A Ordem Matinal (Protocolo dos 7 Minutos)
* **Texto Bíblico Sem Filtro:** 1 versículo e exortação direta para começar o dia no comando.
* **Player Audio-First (2 min):** Narração militar solene e oração guiada para ouvir no fone enquanto arruma a cama, eliminando o "abismo do dia 14" (fadiga de leitura).
* **Ordem de Missão:** Uma tarefa prática de honra e diligência no mundo real.

### 2. A Sentinela (Protocolo SOS 180s)
* **Interrupção Biológica da Fissura:** A onda química de dopamina atinge o pico em 3 minutos e quebra.
* **Técnica 4-7-8 & Choque Vagal:** Exercícios respiratórios e ordens físicas imediatas (água gelada no rosto e flexões de solo) para redirecionar o fluxo sanguíneo.

### 3. A Aliança de Honra (Consequência Social Real no WhatsApp)
* **Pacto 1-to-1:** Sem grupos públicos ou exposição desnecessária; prestação de contas com um mentor, pastor, amigo ou noiva.
* **Sabatina Diária às 21h30:** 3 perguntas binárias com transmissão em 1 toque para o WhatsApp via URL Scheme oficial (`wa.me`).
* **Teologia da Graça (Pv 24:16):** Em caso de tropeço, o botão *"Reiniciar com Graça"* zera o contador com dignidade, preserva o recorde histórico e exorta o homem a se levantar imediatamente sem vergonha neurótica.

### 4. Engrenagem de Vendas & Fachada Segura
* **Dark Obsidian Aesthetic:** Design brutalista minimalista (`#050505`, `#16161A`, `#EA580C`).
* **Checkout Pix Dinâmico:** Gerador de QR Code em tempo real no padrão EMV do Banco Central, timer regressivo de 15 minutos e botão de cópia com fallback universal.
* **Compliance Absoluto para Anúncios:** Comunicação calibrada para Meta Ads e Google Ads, livre de termos proibidos que possam causar bloqueio de contas.

## ⚡ Como Rodar Localmente

### Pré-requisitos
* Python 3.10 ou superior
* Git

### 1. Clonar o Repositório
```bash
git clone https://github.com/SEU_USUARIO/metanoia-app.git
cd metanoia-app
```

### 2. Instalar Dependências
```bash
pip install flet
```

### 3. Rodar o Aplicativo (Desktop / Mobile)
```bash
python main.py
```
*Ou dê dois cliques em `1_RODAR_APP_PC.bat`.*

### 4. Rodar a Landing Page & Checkout Pix
```bash
python -m http.server 8585
```
*Acesse no navegador:* `http://localhost:8585`  
*Ou dê dois cliques em `2_ABRIR_LANDING_PAGE.bat`.*

### 5. Executar Auditoria Completa do Sistema
```bash
python scripts/auditoria_completa.py
python scripts/monitor_saude_sistema.py
```
